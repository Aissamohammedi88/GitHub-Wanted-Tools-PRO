🎯 Pourquoi ce projet ?
Sur le forum officiel GitHub (https://github.com/orgs/community/discussions), les utilisateurs demandent depuis des années des fonctionnalités qui n'arrivent jamais :
❌ Des sous-discussions imbriquées (threads imbriqués comme Reddit)
❌ Une détection de doublons avant publication d'une issue ou discussion
❌ Un résumé automatique des longs fils
❌ Un vote unique (GitHub permet à un utilisateur de voter plusieurs fois sur le même message)
❌ Une recherche wildcard (* et ?) dans les discussions
❌ Des réactions multiples typées (au-delà de 👍/👎)
❌ Des notifications granulaires par discussion
❌ Un export propre (JSON, Markdown, CSV)
Ce projet les implémente tous. En un seul fichier Python. Sans aucune dépendance externe.
